Companion to `docs/dotnet-migration-plan.md`. Produced by a divide-and-conquer audit: every feature/endpoint/contract/behavior of the live Python app was inventoried across 9 subsystems and gap-checked against the plan.

**Audit result:** 367 items checked → **29 covered, 258 partial (under-specified), 80 missing**. The plan's *strategy* is sound; this checklist closes the *contract* gaps so a porter cannot silently drift behavior. The **Python backend is the authoritative source of truth** — not the recovered .NET at commit `7b16806` (it predates today's house style and features; diff against Python, never trust it).

## 0. Plan corrections (contradictions / correctness bugs — fixed inline in the plan)
- [ ] 🔴 **Routes stay FLAT `/api/<router>` — NO API-version segment.** The plan's §3/§6 "adopt org URL-segment versioning (`api/v{version}/...`)" **contradicts** the frozen flat paths the React client hardcodes. Applying it 404s every call. Do **not** add versioning to these routes. *(plan §3/§6 corrected.)*
- [ ] 🔴 **Enums serialize as their exact string NAME, not int and not camelCased.** Configure `JsonStringEnumConverter`; for non-identifier values use `[JsonStringEnumMemberName]`/`[EnumMember]` (BatchModule `author-tests`/`find-bugs`, BatchMode `auto`/`manual`). EF Core must store enums as strings via `.HasConversion<string>()` (EF defaults to int). *(plan §7.2/§7.3/§7.4 corrected.)*
- [ ] 🔴 **camelCase policy carve-outs.** Settings `GET/PUT /config`, ADO-discovery, and `claude-cli/models` return **literal dotted-key dicts** (`ado.organization`) — model as `Dictionary<string,…>` and bypass the camelCase policy. ADO json-patch bodies are serialized **raw** (never through the global STJ camelCase options, which would corrupt `/fields/System.Title` paths). *(plan §7.2 corrected.)*
- [ ] 🔴 **Prompt provenance:** Python agent prompts (`analyst.py`, `tester.py`, `bug_writer.py`, `code_verifier.py`) are authoritative; the recovered .NET prompts must be diffed against them. *(plan §4/§7.6 corrected.)*

- [ ] 🔴 **SSE buffering + SPA fallback** added to plan §2 D4 / §6 (see §11 below).
- [ ] 🔴 **Runtime settings need `IOptionsMonitor`/mutable snapshot** (IOptions is immutable) and per-request ADO auth header (IHttpClientFactory pools handlers) — added to plan B9 (see §2 below).
